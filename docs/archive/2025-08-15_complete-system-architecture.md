## 🔄 核心数据流图

### 1. 用户对话处理流程

```
用户输入 → API Gateway → BFF Service → AI编排器 → 多智能体系统
    ↓           ↓           ↓            ↓            ↓
认证检查      限流控制    路由分发      上下文管理     Agent协作
    ↓           ↓           ↓            ↓            ↓
权限验证      负载均衡    WebSocket    智能路由      任务分配
    ↓           ↓           ↓            ↓            ↓
请求转发      健康检查    REST API     缓存优化      结果汇总

                        Mem0记忆系统 ← → LLM提供商
                             ↕            ↕
                        数据存储层     提示词优化
```

### 2. 多智能体协作流程

```
任务接收 → 智能体注册中心 → 能力匹配 → 协作协调器 → 任务分配
    ↓            ↓            ↓          ↓          ↓
任务分析      Agent发现     权重评估    协作规则    并行执行
    ↓            ↓            ↓          ↓          ↓
上下文共享    负载均衡      优先级排序   冲突解决    状态同步
    ↓            ↓            ↓          ↓          ↓
记忆更新      健康监控      资源分配    结果聚合    最终输出
```

### 3. 记忆管理流程

```
交互数据 → Mem0引擎 → 分类处理 → 存储策略 → 检索优化
    ↓         ↓         ↓         ↓         ↓
数据清洗   向量化     用户记忆   短期存储   语义搜索
    ↓         ↓         ↓         ↓         ↓
格式标准   嵌入生成   会话记忆   中期存储   相关性计算
    ↓         ↓         ↓         ↓         ↓
元数据提取 索引构建   Agent记忆  长期存储   智能推荐
```

## 📊 技术栈详细说明

### 前端技术栈

- **框架**: Next.js 14 (App Router)
- **UI 库**: React 18 + Tailwind CSS + shadcn/ui
- **状态管理**: Redux Toolkit + RTK Query
- **国际化**: next-intl
- **实时通信**: WebSocket + Supabase Realtime
- **构建工具**: Turbopack (开发) + Webpack (生产)

### 后端技术栈

- **API 框架**: FastAPI 0.104+ (Python 3.11+)
- **异步支持**: asyncio + uvloop
- **API 文档**: OpenAPI 3.0 + Swagger UI
- **WebSocket**: FastAPI WebSocket + Redis Pub/Sub
- **任务队列**: ARQ (基于 Redis)
- **中间件**: 认证、限流、CORS、日志

### AI 服务技术栈

- **LLM 集成**: OpenAI SDK + Anthropic SDK + Google AI SDK
- **记忆管理**: Mem0 (开源记忆引擎)
- **向量数据库**: pgvector + Qdrant
- **嵌入服务**: OpenAI Embeddings + 本地模型
- **RAG 框架**: LangChain + LlamaIndex
- **提示词优化**: 自研缓存系统

### 数据存储技术栈

- **主数据库**: PostgreSQL 15+ + pgvector
- **云数据库**: Supabase (PostgreSQL + 实时功能)
- **缓存系统**: Redis 7+ (内存数据库 + 消息队列)
- **文件存储**: Supabase Storage + 本地文件系统
- **搜索引擎**: PostgreSQL 全文搜索 + 向量搜索

### 基础设施技术栈

- **容器化**: Docker + Docker Compose
- **编排**: Kubernetes (生产环境)
- **负载均衡**: Nginx + HAProxy
- **监控**: Prometheus + Grafana + Jaeger
- **日志**: 结构化日志 + ELK Stack
- **安全**: JWT + RBAC + API Rate Limiting

## 🔒 安全架构

### 认证与授权

- **用户认证**: Supabase Auth + JWT
- **API 认证**: Bearer Token + API Key
- **权限控制**: RBAC (基于角色的访问控制)
- **会话管理**: Redis Session Store

### 数据安全

- **传输加密**: HTTPS/TLS 1.3
- **存储加密**: 数据库加密 + 文件加密
- **敏感数据**: 脱敏处理 + 访问审计
