├── contacts/

│   └── [contactId]/

│   ├── page.tsx                 # 文件列表
│   └── [fileId]/
│       └── page.tsx             # 文件详情
├── social/

│   ├── page.tsx                 # 社交首页
│   └── [postId]/
│       └── page.tsx             # 帖子详情
├── plugins/

│   ├── page.tsx                 # 插件市场

#### 1.2 重构前后对比

| 方面 | 重构前 | 重构后 |
|------|--------|--------|
| **路由结构** | 单页面应用，所有功能在 `/` | 多页面应用，每个功能独立路由 |
| **导航方式** | 状态切换 | URL 路由 + 状态同步 |
| **布局复用** | 组件内状态控制 | Layout 文件复用 |
| **代码组织** | 功能混合在单页面 | 功能模块独立目录 |
| **URL 语义** | 不支持深度链接 | 支持语义化 URL |
| **浏览器体验** | 无法后退/前进 | 完整浏览器支持 |

- **加载状态**: 每个路由都可以独立配置加载和错误状态
- **元数据管理**: 支持页面级别的 SEO 优化

### 2. 组件架构优化
- **布局组件分层**: 根布局 → 应用布局 → 功能布局
- **状态管理解耦**: 路由状态与组件状态分离
- **渲染性能优化**: 减少不必要的重新渲染

### 3. 开发体验提升
- **代码组织**: 功能模块清晰分离
- **维护性**: 每个功能独立开发和测试
- **调试友好**: URL 反映应用状态，便于调试

## 已解决的关键问题

### 1. 登录重定向循环 ✅
- **问题**: 成功登录后无法访问主页，持续重定向到登录页
- **原因**: Token 存储与中间件读取不匹配
- **解决**: 同时在 localStorage 和 cookies 中存储认证信息

### 2. SSR Hydration 错误 ✅
- **问题**: `getServerSnapshot should be cached` 无限循环错误
- **原因**: Zustand 选择器函数引用不稳定
- **解决**: 使用稳定的选择器和 useCallback 优化

### 3. 导航状态同步 ✅
- **问题**: URL 变化与导航状态不同步
- **原因**: 缺少路径变化监听机制
- **解决**: AppLayout 中实现 pathname 监听和状态同步

### 4. 中间面板渲染错误 ✅
- **问题**: MiddlePanel 组件最大更新深度错误
- **原因**: useEffect 依赖项包含不稳定的函数引用
- **解决**: 优化 useEffect 依赖项和函数缓存
